# 验证范围

当前公开构建的具体结果见 [发布检查回执](../../validation/publication.json)。本文件说明测试能证明什么。

## 自动化覆盖

- 账号导入、身份/额度归属、可空字段及多 home 绑定。
- 来源切换、完整组合返回、失败恢复、并发写入检测和持久 pending 标记。
- 配置仅修改允许字段，其余字节保留，补齐幂等。
- relay 的 HTTP/SSE、WebSocket、身份头隔离、重定向拒绝、错误保留和有界记录。
- 本地对话预览边界、数据缺失/损坏时的行为。
- 可选传输的隔离主备切换、旧连接保留、恢复守卫和健康状态机。

测试使用合成账号、临时目录及 loopback 服务。真实模型和已安装客户端的条件测试只有显式开启才执行；跳过不算端到端验收。

## 需要在目标机器确认

真实菜单点击、所选客户端的正常退出/重开、登录周期、自启、代理连通性及用户实际额度需要逐项核验。构建和本地测试不能证明目标机器的账号有效或网络可用。

官方身份接口、实际模型路由、外部浏览器、连接器和手机 Remote 是不同验收项。保留身份不会自动保证每项能力；不能从模型目录、HTTP 200 或 WebSocket 握手推出完成生成与计费归属。

## 已知边界

默认不修改历史；旧来源、密文和模型跨组合可能不兼容。运行中的旧 helper 不会因覆盖 App 文件而自动升级。出现活动写入者或无法安全恢复的状态时保留提示，不通过强杀或删除保护记录绕过。

本次公开发布不执行生产安装、正式账号切换或真实模型请求，不包含个人现场记录。
